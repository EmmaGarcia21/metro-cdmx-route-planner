
# Metro CDMX - Route Planner

A Python application designed to calculate optimal routes in Mexico City's metro network.

## Features
- Route calculation using the A* search algorithm.
- Graph-based representation of metro stations and connections.
- Travel time estimation.
- Consideration of metro opening schedules.
- Accessibility considerations for passengers with reduced mobility.
- Graphical interface built with Tkinter.
- Visual route representation and train animation.

## Technologies
- Python
- NetworkX
- Tkinter
- Pillow
- Graph Algorithms
- A* Search

## Project Structure
- `metro.py`: Route calculation and metro network logic.
- `metro_interfaz.py`: Graphical application interface.

## How to run
Install the required dependencies and execute:

```bash
python metro_interfaz.py
```
